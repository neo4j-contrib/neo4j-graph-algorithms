= Closeness Centrality

_Closeness Centrality_ of a node is a measure of centrality in a network, calculated as the sum of the length of the shortest paths between the node and all other nodes in the graph. Thus the more central a node is, the closer it is to all other nodes.

== Algorithm explanation on simple sample graph

- counts farness in each msbfs-callback
- divides by N-1

Graph:

( A )<==>( B )<==>( C )<==>( D )<==>( E )

Calculation:

`N = 5`        // number of nodes

`k = N-1 = 4`  // used for normalization

     A     B     C     D     E
 --|-----------------------------
 A | 0     1     2     3     4       // farness between each pair of nodes
 B | 1     0     1     2     3
 C | 2     1     0     1     2
 D | 3     2     1     0     1
 E | 4     3     2     1     0
 --|-----------------------------
 S | 10    7     6     7     10      // sum each column
 ==|=============================
k/S| 0.4  0.57  0.67  0.57   0.4     // normalized centrality
